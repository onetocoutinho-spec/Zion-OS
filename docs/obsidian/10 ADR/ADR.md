# 🧱 Architecture Decision Records (ADR)

> Registro imutável das **decisões de arquitetura**: contexto, decisão, alternativas e consequências. Um ADR nunca é apagado — quando superado, é marcado **Superseded** por um novo. Novo ADR usa o [[Template ADR]].

## Como criar um ADR

1. Copie o [[Template ADR]] para esta pasta como `ADR-NNNN-titulo-curto.md` (NNNN sequencial).
2. Preencha contexto, decisão, alternativas e consequências.
3. Referencie o documento de arquitetura afetado ([[Arquitetura]]) e conceitos ([[Glossário]]).
4. Status: `Proposed → Accepted → (Deprecated | Superseded por ADR-XXXX)`.
